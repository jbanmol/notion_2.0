## ADDED Requirements

### Requirement: Matrix Character Scrambling Decryption Effect
The system SHALL apply visual cypher glyph character-scrambling loop animations to result item titles when opening or re-filtering search results inside the command palette.

#### Scenario: Searching triggers visual decoding
- **WHEN** the command palette renders or updates fuzzy query search items
- **THEN** result titles SHALL cycle through randomized futuristic unicode characters for 200ms before instantly decrypting and resolving to readable plain titles.
